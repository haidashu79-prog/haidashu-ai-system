# 01 · 快速开始

按顺序做完这四步，你就能跑起来。

---

## 第 1 步：克隆仓库

```bash
git clone https://github.com/haidashu79-prog/haidashu-ai-system.git
cd haidashu-ai-system
```

---

## 第 2 步：认识目录

```
haidashu-ai-system/
├── README.md            体系总览
├── ARCHITECTURE.md      架构说明（改之前先读这篇）
├── docs/                各体系详细说明
├── skills/              ← 真正干活的东西都在这
│   ├── opc-expert-team/         OPC 专家团
│   ├── haida-zimeiti-workflow/  选题与文案
│   ├── haida-video-pipeline/    八步出片
│   ├── ai-dispatch/             项目台调度
│   ├── zhinao-expert-team/      多租户交付
│   └── zhinao-wiki/             知识库治理
```

每个技能目录结构一致：

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 入口。定义触发条件、流程、输出规范 |
| `references/` | 规格文件。写死的字数、结构、清单 |
| `meta.json` | 元信息，客户端识别用 |

---

## 第 3 步：装进你的 AI 客户端

本体系按「技能目录」组织，主流支持自定义技能的客户端都能直接读：

1. 打开客户端的技能 / 插件目录（一般是 `~/.<客户端名>/skills/` 之类）
2. 把 `skills/` 下需要的技能**整个文件夹**复制进去
3. 重启客户端，或刷新技能列表

**不要只复制 `SKILL.md`** —— references 里的规格是缺不了的，少了它 AI 会自己编规格。

---

## 第 4 步：改路径（重要）

原环境的所有路径已脱敏为三种占位符：

| 占位符 | 含义 | 怎么改 |
|---|---|---|
| `~` | 你的用户主目录 | 一般不用改 |
| `$MARVIS_HOME` | 你所用 AI 客户端的数据目录 | 换成实际路径 |
| `$WORKBUDDY_HOME` | 引擎运行目录 | 换成实际路径 |

全仓库搜索替换即可：

```bash
grep -rn 'MARVIS_HOME\|WORKBUDDY_HOME' skills/ | head
```

例如 `skills/zhinao-wiki/SKILL.md` 里写着 `MW="$MARVIS_HOME/skills/market/marvis-llm-wiki"`，把 `$MARVIS_HOME` 换成你的实际目录即可。

---

## 只跑内容生产线（最快路径）

不想装引擎，只想让 AI 帮你写一条口播稿：

1. 复制 `skills/haida-video-pipeline/` 和 `skills/haida-zimeiti-workflow/` 到技能目录
2. 在对话里说：「出一条片子，选题你定」
3. AI 会依次跑到选题 → 你选 1 条 → 归一 → 写稿 → 去 AI 化 → 封面三选一 → 剪辑小样 → 发布清单 → 归档
4. 你在三处确认：选题、封面、成片小样

跳过规则：只说「今天出 3 条文案」→ 只跑写稿段，不碰封面剪辑。

---

## 关于第 1 层引擎

第 1 层（记忆 / 采集 / 检索 / 自省）属于作者私有资产，**不随本仓库发布**。

要用这套方法，引擎可以用任何东西顶替：Obsidian 库 + 检索脚本、Notion、现成 RAG 工具，或 AI 客户端自带的长期记忆。唯一要守住的契约是——**结论必须能指回来源条目**，指不回去就明说「没有可靠来源」。

其余三层（调度、内容生产线、交付）不依赖具体引擎实现，换掉引擎照常运转。

---

## 常见卡点

| 现象 | 原因 | 处理 |
|---|---|---|
| AI 不按规格写，字数忽长忽短 | 只复制了 SKILL.md，没带 references | 整个文件夹复制 |
| 说「走流水线」没反应 | 客户端没识别技能名 | 直接说「用出片总控，出一条片子」 |
| 引擎报路径错误 | 占位符没替换 | 按第 4 步全局替换 |
| 引擎搜不到东西 | 渠道被网络挡了 | 跑 `test-sources` 看渠道健康台账，失效渠道会自动停用 |
