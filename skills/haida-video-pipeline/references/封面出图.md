# 第 5 步：标题与封面

## 一、标题（先定，再出图）

| 项 | 规格 |
|---|---|
| 字数 | 4–6 字 |
| 标点 | **0 个**，不许有逗号、句号、问号、引号 |
| 写法 | 把核心反差压成一句；优先用招牌句式 `X 不叫 X` |
| 禁用 | 不写"震惊""必看""揭秘"，不用感叹号，不用数字堆砌 |

合格例：裁员不叫裁员｜缴费不叫缴费｜体面最贵
不合格例：震惊！公司竟然这样裁员？｜关于社保缴纳你必须知道的三件事

---

## 二、封面出图规格

**比例 3:4**（抖音竖版安全区），一次出 **3 张**，让老板选 1 张。

固定提示词模板（直接套，只替换「标题」）：

```
生成一张竖版口播视频封面，比例 3:4。
主标题文字：「{标题}」，4-6 字，超粗黑体或综艺体，白色字加黑色描边，占画面中部偏上，字距紧凑。
副标题（可选，一行）：{一行内讲完的钩子}，字号约为主标题三分之一。
画面风格：中年男性口播场景，写实纪实感，暖调，浅景深，背景虚化的老小区或街边茶馆。
表情：皱眉、撇嘴、对着镜头说话的中近景，不要笑脸。
配色：主色深红或墨绿，文字与背景强对比，手机小图也能一眼认出。
禁止：任何水印、二维码、平台 logo、复杂装饰、英文字母、多余小字。
一次输出三张不同排版：①文字居中压图 ②下三分之一文字区 ③左右分栏（左人右字）。
```

## 三、出图后必须自查（缩到手机缩略图大小看）

- [ ] 标题在缩略图状态下还能读清
- [ ] 没有一个英文字母
- [ ] 没有水印和二维码
- [ ] 三张里至少有一张是"人脸 + 大字"，其余可玩版式
- [ ] 标题文案与视频标题完全一致，不许模型自己改字

**模型改字是常见毛病**：出图后逐字核对标题，错一个字就重出，不许将就。

---

## 四、封面存档

选定后重命名为 `{日期}-{标题}-封面.jpg`，放 `output/`。三张都留，下次同类题可复用排版风格。
