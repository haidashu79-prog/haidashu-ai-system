# 爆款归因框架（第 2 步专用）

目的只有一个：**把一个爆款拆到能抄的程度**。看完要能说出「这条我下一稿偷哪一手」。

## 一、五维打分（每维 1-5 分，满分 25）

| 维度 | 5 分长什么样 | 1 分长什么样 |
|---|---|---|
| **钩子力** | 前 3 秒就是冲突/数字/反常识，第一句就想让人停手 | 先铺垫背景，"随着……"开头 |
| **利益相关** | 直接戳钱袋子/孩子/身体/面子，谁看都觉得跟自己有关 | 跟普通人的日子不沾边 |
| **可吵性** | 评论区能吵成两派，有人骂有人顶 | 看完点个头，无话可说 |
| **认知反转** | 有"原来是这么回事"的揭底时刻，把常识翻过来 | 全程顺着说，没新东西 |
| **身份代入** | 替普通人把话说了，看完想"这就是我" | 站在岸上点评，跟观众无关 |

**分档**：
- **≥20 分 → 结构级爆款**：爆在写法上，可以整套偷
- **16-19 分 → 选题级爆款**：爆在题目上，偷题目不偷结构
- **<16 分 → 流量偶然**：别硬吹成规律，**不许把偶然说成方法**

## 二、结构解剖（每条必填）

```
标题原句：
平台 / 账号 / 数据（点赞 · 评论 · 收藏）：
一句话内容：
钩子原句：
钩子类型：反常识 / 数字 / 冲突 / 提问 / 骂街 / 现场感 / 借别人的话
段数 / 平均段长（估）：
转折出现在第几段：
收尾方式：给办法 / 无奈自嘲 / 一句总结 / 反问
```

## 三、数据侧写（判断"爆在哪"）

看四个数的比例关系，能反推爆的原因：

| 现象 | 说明什么 |
|---|---|
| 赞高、评低 | 认同型爆款，观众点头不说话 → 选题戳中共识，可复制 |
| 评高、赞低 | 争议型爆款，吵起来了 → 选题有对立面，抄题目但要控立场 |
| 藏高、赞中 | 干货型爆款，观众存起来备用 → 内容结构值钱，可抄骨架 |
| 转高 | 情绪型爆款，观众替你说给别人听 → 情绪浓度够，抄情绪节奏 |

数据拿不到就写「未获取」，**不许估、不许编**。

## 四、输出模板（逐条照填）

```
【视频标题】（平台｜点赞X · 评论Y · 收藏Z）
- 钩子：原句「……」→ 类型：
- 结构：__ 段，平均段长约 __ 字，转折在第 __ 段
- 五维：钩子 _ / 利益 _ / 可吵 _ / 反转 _ / 代入 _ = __ 分（分档：___）
- 爆在哪：一句话
- 可复用招式：____（可执行，例如「先甩一个反常识判断，第二段才交代事由」）
```

## 五、收口（做完必须给）

**今日这批爆款的共性 2-3 条**，写成可以直接当写作指令的话，例如：

> ① 都在第一句就给判断，不交代背景；
> ② 都拿一个具体数字当锚（三千二、八块五）；
> ③ 收尾都不给大道理，只给一个能做的小动作。

这 2-3 条直接进第 3 步，当作本次 5 篇稿子的硬指令。

## 六、常见可复用招式（参考弹药）

- 反常识开场：「最穷的不是没钱的，是天天算钱的」
- 数字锚：开口就甩一个小钱的具体数
- 借别人的话起手：「网上都在说……我有点不敢苟同」
- 层层追问：连问三层，末层落在最土的实话上
- 短词递进：「认输了，服了，放弃了，躺平了」
- 算账收口：把大事算成一天几块钱
- 无奈自嘲收尾：「咱这帮老登，谁都没辙」
