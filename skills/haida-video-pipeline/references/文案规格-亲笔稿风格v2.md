# 海大叔风格画像 · 老板亲笔校准版（2026-10-04）

样本：老板本人手写的 5 篇稿子（2026-10-04 提供）。
**这 5 篇的规格与 1835 篇老库统计有出入，以本文件为准。** 尤其段落长度、开头报题、结尾三段式，是老库里没量出来的新特征。

---

## 一、量化规格（实测，不是估的）

| 项 | 实测真值 | 与老库的差异 |
|---|---|---|
| 单篇字数 | 800–850 字 | 老库 800–1000，**这次卡得更死** |
| **逗号分段平均长度** | **9–11 字** | 老库 26 字，**新稿短了一半** |
| 段落数 | 75–95 段 | 老库 20–25 段，**段数暴增 3 倍** |
| 问号 | 5 篇里只有 1 个 | 老库强调呛声反问，**新稿基本不用问号** |
| 开头 | 每篇带序号 + 一句话报题 | 老库没这规矩 |
| 结尾 | 签名 + 毒舌金句 + "你品你细品" 三段 | 老库只有签名 |

**最重要的一条：新稿的句子比老库短一半。** 9 到 11 字一段，念起来是一口气往下滚的连珠炮，不是老库那种中长句。写新稿必须按这个来。

---

## 二、开头：序号 + 报题（新规矩）

老板这 5 篇全是这个格式：

```
1 这期还是聊钱，钱越来越难挣，这是大家的感同身受
2 听到一段对于挣钱的解读，挺有意思
3 现在的闲人就是太多了
4 钱重要不重要，谁都知道很重要
5 人的这个心气其实很重要
```

格式：`序号 + 空格 + 一句话报题`

报题的三种写法：
- **直给式**：`这期还是聊钱` / `现在的闲人就是太多了`
- **引用式**：`听到一段对于挣钱的解读，挺有意思`（先说从哪儿听来的，再进正题）
- **定义式**：`人的这个心气其实很重要`（把话题词拎出来当场下定义）

**不许铺垫**，报完题立刻往下走。老板不写"近日来""今天聊聊"。

---

## 三、结尾：三段式（新规矩，必须写全）

老板这 5 篇结尾都是三层，缺一层就算没写完：

```
第一层·签名：这个世界破破烂烂，总有人在缝缝补补
第二层·毒舌金句：最好的办法是一切都清零吧，那是做梦
第三层·收口：你品你细品
```

金句要在签名**之后**，别放签名前面。这是老板的固定顺序，之前的稿子经常搞反。

**金句的样子**（都是土话，都是自嘲或毒舌，不是励志）：
- `最好的办法是一切都清零吧，那是做梦`
- `穷不可怕，可怕的是你把一辈子的劲儿，全花在"熬过今天"上`
- `他不是在缝补，他是在插针`
- `往后能笑到最后的，不是挣得最多的，是活得最久、摔得最轻的`
- `就算啥也不是，也要风生水起`
- `咱们这代人，真的是最后一代还在给父母养老的人`

**收口**：`你品你细品`（这 5 篇全有，5 篇里 4 篇用它收）

## 四、招牌句式（老板这批用得最多的）

### 4.1 排比（每篇至少 2 处，最多 5 连）

**用法一·并列砸**：一串同结构的词，不解释，连着甩
```
认输了，服了，放弃了，摆烂了，躺平了
```
字数 4-6 个一词，3-5 个连排，念起来要有节奏。

**用法二·叠加推**：同一句式反复，每次换一个更狠的后果（篇4 示范）
```
因为囊中羞涩，你也会慢慢疏远了很多人。
因为囊中羞涩，你也会改掉很多坏毛病。
因为囊中羞涩，你也会变得会过日子了。
因为囊中羞涩，你也会对自己越来越没有信心。
因为囊中羞涩，低谷的时候，连父母都不想联系。
```
固定前半句，后半句一次比一次扎心，**收尾那句要最狠**。

**用法三·正反撞**：前半句给理由，后半句推翻
```
他嫌贪财不好，殊不知贪财没有成本，好色得花钱。
```

**用法四·方言狠话**（带东北味的具体话）
```
他不出门他穿啥衣服你说
你凭啥这么干
```

**纪律**：每句字数尽量接近（长短不齐念起来散）；最多 5 连（超过变清单体）；**排完必须跟一句总结或转折**，光排不给结论显得水；排比里不许有书面语。

### 4.2 层层追问（把荒诞感顶上去）

**推进公式**：
```
承认对方说的有一点道理
  ↓ 顺着这个理往下推一步
  ↓ 再推一步
  ↓ 推到最荒谬、最扎心的一层
  ↓ 收一句：这还有理吗
```

**层数：3 到 5 层。** 少于 3 层没劲，多于 5 层啰嗦。

篇3完整示范（连环甩问题，句号代替问号）：
```
那英缅怀刘欢这个事也能找茬。
那念稿子还能不能脱稿呢。
那脱稿就是即兴，如果脱稿有毛病，那还能不能即兴讲什么和做什么呢。
如果即兴也有毛病，那喜怒哀乐的情绪还能不能表达呢。
如果情绪表达也有毛病，那还是不是个有血有肉的人呢。
你到底是个什么变得，咋就那么闲呢。
```

**另一路，往人身上推**：
```
他出题有没有毛病。没有。
这歌有没有毛病。没有。
他这行为有没有毛病。有。闲的。
```

**关键禁忌：追到最后必须自己收住，不许自己下场说破道理。** 让观众自己得出结论，比你告诉他更有劲。

### 4.3 引经据典（用老百姓都听过的那句）

**只能用三类，一句书本里的原句都不许**：

*一·老祖宗的话*（给观点垫底，立刻翻成大白话）
```
老祖宗的话糙理不糙，虎父无犬子，龙生龙凤生凤。
听着刺耳，往深里品，藏的是对血脉传承的认领。
```

*二·俗语谚语*（当结论，一句收一段）
```
树倒猢狲散，人走茶就凉
擒贼先擒王
光脚的不怕穿鞋的
鸡蛋碰石头
吃了秤砣铁了心
```

*三·歇后语*（当包袱，抖机灵）
```
狗咬吕洞宾，不见得人心
王婆卖瓜，自卖自夸
吃人家的饭，还砸人家的锅
```

**万能模板（照着套）**：
```
老祖宗有句话[, X X X]，[这话/听着]糙[不糙/挺刺耳]。
但往深了品，它说的是[大白话一]。
[扣回本篇主题的一句毒舌]。
```

**三条纪律**：
1. **只用带土味的**（俗语、歇后语、老话），**不引《论语》《史记》里的原句**，一用就露怯
2. **引完必须翻成大白话**，不能引完就走
3. **一篇最多 2 处**，多了掉书袋，短视频听不过来

**立刻出错的例子**：
- 错：`《左传》有云，居安思危` —— 太书面，观众掉头就走
- 对：`老祖宗的话糙理不糙，虎父无犬子，龙生龙凤生凤。听着刺耳，但往深了品，藏的是对血脉传承的认领。`

### 4.4 其他句式

- **X 不叫 X，叫 X**：`今天挣今天的钱，那叫糊口；为后天练本事，那才叫奔日子`
- **不是…是…**（不用问号，用陈述砸）：`不是你不够努力，是这个池子就这么大`
- **反问不写问号**：`那英这人有毛病吗？没有` —— 自问自答，全用句号，句尾往下压
- **反问带刺**：`他不出门他穿啥衣服你说` —— 结尾缀"你说"，不用问号
- **数字落地**：`五万的车` `十万的` `五十万的新能源车` —— 爱用整数，不爱用小数

## 五、三大技法怎么配合着用

写任何一篇之前，先问自己这三样用没用：

| 技法 | 干什么用 | 一句话记 | 硬指标 |
|---|---|---|---|
| 层层追问 | 把荒诞感顶上去 | 顺着对方的话往下推，推到最荒谬处停住 | 3-5 层，追完不许自己说破道理 |
| 排比 | 造气势，一口气把情绪推到位 | 同结构的话连着甩 | 每篇至少 2 处，最多 5 连，排完必须给总结 |
| 引经据典 | 给观点垫底，显得你有根 | 老祖宗的话糙理不糙 | 一篇最多 2 处，只用俗语歇后语，引完必须翻成大白话 |

**三样一起用的骨架**（篇1 就是这个结构）：
```
报题 → 抛疑问（为啥钱难挣）
  ↓
【引经据典】用老话垫底
  ↓
【层层追问】闭着眼都能挣 → 那为啥现在不行 → 推到最后
  ↓
【排比】大企业外包裁员，小企业压缩开支，个人不敢花钱
  ↓
算一笔具体的账（十万首付买五十万车）
  ↓
毒舌金句 → 三段收尾
```

**三样都是"土"的**——追问要土、排比要土、引经据典要土。**任何一样往"雅"的方向走就是掉价。**

## 六、老板这批的三个新特点

### 1. 机制要讲透，但用土话
篇1讲信贷，全篇没有"信贷"以外的专业词，就是"把你未来几年要挣的钱提前拨到今天让你花"。**先讲机制，再算一笔具体的账**（十万首付买五十万车），账算完观众自己就懂了。

### 2. 层层追问，把荒诞感顶上去
篇3是最典型的，示范见 4.2。**每一层都往前推一步荒诞**，推到最荒谬处自己停住，不点破。

### 3. 自嘲收尾，不硬撑
篇5结尾：`咱也没经历过啊，跟那些年亲人一样，我们这群老登，也他妈头一回经历这事，谁都没辙`

老板不装权威，认"我也没辙"。这批稿子比老库多了一层"我也在局里"的姿态。自嘲最多 2 处，多了成卖惨。

## 七、语气词表（照着用）

- **东北底色**：咱们、你说你、你就说、我跟你说个事、有病没、咋、啥、多损、整、贼、老登们、犊子、扯淡、完犊子
- **句尾**：啊、吧、呢、呗、啦、哈、是吧、你品
- **骂人的分寸**：`都他妈不敢借了` `他妈的` 这类脏话老板自己会写，AI 写的时候**适度即可，别比老板更脏**
- **不发问，用陈述**：`为啥呢`、`你说气人不气人` —— 问号全省掉

---

## 八、必须避开（老板这批里完全没有的）

- 书面语：显著、诸如、届时、折射、凸显、传导机制
- 英文单词：一个都没有（连 AI 都写成"人工智能生成的形象"）
- 成语堆砌：破局、闭环、护城河、赛道（全不出现）
- 编号清单：第一招/第二招、记住三点——**连"三条建议"都不写编号，全靠"头一条/再一句"这种顺嘴的说法**
- 自我修正痕迹：正文里绝不出现"不对""等等"
- 观点正确但没人味的话：不说"我们要理性看待"，说"他不是在缝补，他是在插针"
- **书本里的典籍原句**（《论语》《史记》这类）—— 引经据典只用俗语歇后语老话
