# 第 7–8 步：发布与归档

## 一、发布包四件套（缺一不算完）

| 件 | 规格 |
|---|---|
| 标题 | 4–6 字，0 标点（与封面一致） |
| 简介文案 | 1–2 句，先抛冲突再补一句人话；带 3–5 个标签 |
| 标签 | 固定的：#海大叔 #中年 #民生；按题补 1–2 个具体标签（不蹭无关热点） |
| 发布时间 | 见下表 |

## 二、发布时段（按账号实际数据调，没数据先用这个）

| 时段 | 适合内容 |
|---|---|
| 07:00–08:30 | 民生资讯、早间评论（通勤刷手机） |
| 11:30–13:00 | 道理流、认知类（午休看长一点） |
| 19:00–21:30 | 主推重磅题、骂街类（流量最高） |
| 22:00–23:30 | 中年情绪、亲子、健康（睡前共鸣） |

## 三、平台适配（一条内容改三版，不要直接搬）

- **抖音/视频号**：竖版 3:4 封面，前 3 秒必须出冲突，简介短、狠
- **公众号**：可加深，开头保留钩子，正文分段但保持口语，结尾留签名
- **小红书**：第一人称、每条带一个具体场景，标题可带数字

## 四、合规红线（发布前逐条过）

- [ ] 不造谣不传谣，数字有出处
- [ ] 敏感案件不点名、不点地区、不定性
- [ ] 不贩卖无出路的焦虑
- [ ] 不攻击地域和群体
- [ ] 不碰政治敏感
- [ ] 图文中无未经授权的人脸（除自己）

---

## 五、第 8 步：归档（这一步最容易被偷懒，必须做）

发布后按 `{YYYYMMDD}-{标题}` 建一个归档目录，放：

```
{YYYYMMDD}-{标题}/
├── 文案.txt          （最终成稿）
├── 封面.jpg          （选定那张）
├── 发布信息.md       （标题/简介/标签/发布时间/链接）
└── 数据回填.md       （见下）
```

## 六、数据回填（发布后 48 小时）

```
播放量：
完播率：
点赞 / 评论 / 收藏 / 转发：
涨粉：
评论区最高赞的三条评论：
```

**三行结论（必须自己写，不许空着）**：
1. 这条爆没爆，按 `references/爆款归因框架.md` 五维打分给个分档
2. 爆在写法还是爆在题目（结构级 / 选题级 / 流量偶然）
3. 下一条要偷哪一手，或者要避开什么

## 七、回写知识库

结论写进 `~/Desktop/海大叔知识库/09_账号拆解/`，同一格式追加。
**只写有依据的结论**：偶然爆的就说偶然，不许硬吹成方法论。
