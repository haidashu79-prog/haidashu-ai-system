# 第 3 步 · 文案生成规范（海大叔版）

## 目标

读取海大叔知识库往期文案，提炼其**人生经历、观点与语言风格**，生成指定选题的口播文案成品稿（海大叔风格：北京街溜子老炮、犀利口播）。

## 第一步：读取与提炼（风格建模）

1. **读取往期文案**：默认读取 `~/Desktop/海大叔知识库/`（风格画像、口播文案SOP、开头钩子库、结尾金句库、去AI味清单、金句与比喻库），并从 `04_成稿归档/` 抽样 2-3 篇真实成稿通读。若知识库不存在或用户指定其他文案，读取用户提供的文件。
2. **提炼人生经历与观点**：归纳往期文案中反复出现的个人经历（摔过的跟头、踩过的坑）、核心观点与立场（站普通人、反割韭菜等），新文案只能沿用**已有经历与观点**，禁止虚构新经历、新成绩。
3. **提炼语言风格**：记录口语词、短句节奏、段长、称呼、比喻习惯、排比与反问的使用频率，新文案声纹必须贴近。

## 写作三条规范（逐条对照）

### 1. 开头钩子规范
- 开头优先呈现**反差、结果、冲突或认知误区**
- 前三行内说明「这条内容与我有什么关系」（让观众知道这事关自己）
- 删除无效寒暄、背景铺垫和故意制造焦虑的表达
- 可参考钩子模式：反常识判断 / 直接提问 / 数字冲击 / 现场感 / 新闻切入 / 自嘲预警

### 2. 内容结构规范
- 按「**提出问题 → 解释原因 → 给出方法 → 展示结果**」组织内容
- 每个段落只解决一个问题，段落间逻辑递进
- 调整信息顺序：核心价值前置、干货层层递进
- 数据与案例必须带出处或真实细节，不空谈

### 3. 去 AI 感规范
- 删除模板化表达（「综上所述」「值得注意的是」「不难发现」）、空泛金句、整齐排比与重复总结
- 抽象形容词替换为具体场景、人物动作、数字或真实细节
- 保留自然口语感；**不得虚构经历和成绩**
- 量化判定线（海大叔基准）：平均段长 ≤40 字、问号 ≤2 个/篇、引号 ≤1 处/篇，任意两项超标即重写

## 字数规格

- 默认 780-1000 字（中位 878），21-26 段；**以用户当轮明确指令为准**
- 低于 600 字算短稿、高于 1200 字算长稿，除非用户指定

## 自检清单（出稿后必检）

1. 前三行内是否有反差/冲突/认知误区，并说明与观众的关系？
2. 结构是否「提出问题→解释原因→给出方法→展示结果」、每段只解决一个问题？
3. 核心价值是否前置、干货是否递进？
4. 有无模板化表达、空泛金句、整齐排比、重复总结？（有则删）
5. 有无虚构的经历、数据、成绩？（禁止）
6. AI 味量化线是否达标（段长/问号/引号）？

## 输出格式

```
## <选题标题>（口播文案）

<成品稿全文，一段一句或两三句，直接可发>
```
