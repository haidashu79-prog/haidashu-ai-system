# 第 2 步 · 选题库搭建规范（海大叔版）

## 目标

基于第 1 步抓取的爆款视频与改编角度，结合海大叔定位（中年老炮、站普通人立场），生成 3-5 个有爆款潜质的新选题。

## 选题前置：查重

出选题前先查 `~/Desktop/海大叔知识库/02_选题池/` 下的已写清单（历史全量1368篇 + 各批次），已写过的选题直接跳过，避免重复。

## 选题生成规则

1. **场景化**：围绕**中年人群的真实生活场景**展开（饭局、深夜刷手机、孩子学费、父母体检、被裁当天、还房贷、摆摊副业），一个选题对应一个清晰、可感知的使用场景。
2. **问题具体化**：提炼具体问题、情绪与需求（如「40岁被优化后瞒着家里每天假装上班」），**禁止**「自我提升、变得更好」「保持积极心态」等宽泛表达。
3. **情绪锚点**：每个选题要能戳中中年人群的真实情绪（焦虑、不甘、共鸣、愤怒、释然），情绪越具体越有传播力。
4. **改编来源**：每个选题须注明改编自第 1 步的哪条爆款、用了什么改编角度（换人群视角 / 换立场 / 换场景 / 换表达形式）。
5. **海大叔适配**：优先选有可撕的「皮」的选题（资本套路、割韭菜、无良商家、政策槽点、专家放屁），与海大叔「站普通人、守住本金别瞎折腾」的立场一致。
6. **爆款潜质**：自检该选题是否具备话题性（能引发评论争论）与可拍性（30-60 秒能讲清）。

## 每个选题必含三要素

| 要素 | 说明 | 示例（中年赛道） |
|---|---|---|
| 帮谁 | 明确目标人群画像 | 40岁被裁、背着房贷、不敢跟家里说的中年男人 |
| 解决什么问题 | 具体问题/痛点/情绪 | 被裁后不敢告诉家人，每天假装上班的羞耻感与孤立无援 |
| 提供什么价值 | 信息/方法/情绪价值 | 一套「缓冲期三件事」：稳住现金流、谈赔偿、规划再就业 |

## 反例与正例对照

| 类型 | 例子 | 问题 |
|---|---|---|
| 反例 | 「中年人要不断提升自己」 | 宽泛、无场景、无具体问题 |
| 反例 | 「如何让自己变得更好」 | 空泛金句，无法感知 |
| 正例 | 「40岁被裁那天，我做了3件事，没让家里知道」 | 有场景、有情绪、有方法 |
