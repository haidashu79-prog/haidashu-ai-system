# 第 1 步 · 爆款抓取规范

## 目标

抓取近期热点中的优质爆款视频，筛选出**符合账号定位**的 10 条选题灵感，每条附完整信息与「看原视频」跳转链接。

## 数据源检索

1. **热点榜单**：优先检索 B站、今日头条、微博的近期热点/热榜（时效 24-72 小时内优先），用 web_search / web_fetch / 浏览器访问热榜页面。
2. **关键词扩展**：结合海大叔赛道与内容类型扩展搜索词：中年成长、中年危机、中年创业、副业、失业、再就业、民生、经济数据、社保养老、房价、消费、职场、被骗、割韭菜、社会新闻等，检索各平台近期高赞视频。
3. **交叉验证**：同一热点多平台出现时取数据最全的一条；检索失败或数据缺失时如实说明，禁止编造数据与链接。

## 筛选标准

满足以下条件越多越优先：
- 主题与账号赛道、内容类型强相关（成长/学习/职场/创业/情感/时事等）
- 视频数据亮眼：高点赞、高收藏、高评论（评论量是爆款先行指标）
- 有可二创的空间：观点可延伸、事件可评论、方法可迁移
- 时效性：近期发布或近期热度上升

## 每条必含 7 个字段

| 字段 | 说明 |
|---|---|
| 视频标题 | 原视频标题（如实引用） |
| 视频数据 | 点赞数、收藏数、评论数（注明采集时间与来源平台） |
| 视频标签 | 成长 / 学习 / 职场 / 创业 / 情感 等标签归类 |
| 视频内容 | 一句话总结视频核心内容 |
| 选题适配度 | 为什么适合这个账号来做（结合人设与赛道说明） |
| 改编角度 | 结合账号定位如何进行二创（给出可落地的角度） |
| 看原视频 | 可跳转的原视频链接，点开即能观看 |

## 输出格式

```
## 今日选题灵感（10条）

| # | 视频标题 | 点赞 | 收藏 | 评论 | 标签 | 内容总结 | 选题适配度 | 改编角度 | 看原视频 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | ... | ... | ... | ... | ... | ... | ... | ... | [看原视频](链接) |
...

（附）数据来源与采集时间说明
```

## 硬性要求

- 视频标题、数据、链接必须来自真实检索结果，禁止编造
- 每条「看原视频」必须是真实可访问链接（B站 av/BV 链接、头条文章/视频链接、微博链接等）
- 数据采集时间要注明，避免误导
